Pattern Cheat Sheet

Pattern When to Use Key Problems
Two Pointers Sorted array, pair finding 3Sum, Container With Most Water
Sliding Window Subarray/substring with constraint Min Window Substring, Longest Substring
Binary Search on Answer Min/max optimization Koko Eating Bananas, Split Array
Monotonic Stack Next greater/smaller element Daily Temperatures, Histogram
BFS Shortest path (unweighted), level order Rotting Oranges, Word Ladder
DFS + Memo Tree/graph with overlapping subproblems Longest Increasing Path
Union Find Connected components, cycle detection Redundant Connection
Topological Sort Dependency ordering Course Schedule
0/1 Knapsack Subset selection with constraint Partition Equal Subset Sum
Interval DP Merge/split ranges optimally Burst Balloons
State Machine DP Multiple states per position Stock Buy/Sell with Cooldown
