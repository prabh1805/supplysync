# Daily Schedule — Hour Allocation

---

## Weekdays (Mon–Fri): ~10 hours/day

| Block | Hours | What |
|-------|-------|------|
| DSA (Leetcode) | 2.5 hrs | Daily problem set from DSA_30_DAYS.md |
| Competitive Programming | 1 hr | Codeforces problems / virtual contests |
| Java Core / Spring Boot | 1.5 hrs | Theory from JAVA_CORE.md or SPRING_BOOT.md |
| Project (SupplySync) | 2 hrs | Implement what you learned + new features |
| System Design | 2 hrs | 1 concept + 1 design problem |
| Review + Plan Tomorrow | 1 hr | Notes, weak areas, next day prep |
